# PowerBI_Healthcare_dashboard-
Created a Dashboard for Healthcare using Power BI.
Healthcare Dashboard is an hospital Workflow Which shows the overall working of the hospital.
- It has Patience ID which when selected Shows the history of Particular patient.
- Admit Date
- Discharge Date
- Follow up Date
- Billing amount
-Dashboard  include donat chart which includes all the feedbacks of all the doctors.
-It includes line chart which shows health insurance amount against Diagnosis.
